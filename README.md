## 📝 Описание проекта
Программа представляет собой классическую 2D-аркаду **Flappy Bird**, написанную на Python с использованием строгого объектно-ориентированного подхода. Цель игры — управлять птицей, пролетая между бесконечно генерируемыми трубами и избегая столкновений. В проекте реализована процедурная генерация препятствий, физика свободного падения (гравитация) и динамический подсчет очков.

## ✨ Функциональные возможности

### Основной функционал
- 🐦 **Управление:** Прыжок птицы с помощью клавиши `Пробел`.
- 🚧 **Генерация мира:** Процедурная генерация препятствий (труб) со случайным расположением зазора.
- 💥 **Физика и коллизии:** Определение столкновений с трубами и вылета за границы экрана.
- 🔄 **Игровой цикл:** Экран поражения (Game Over) и мгновенный перезапуск игры клавишей `R`.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/GubinEgor-Bee/flappy_bird.git](https://github.com/GubinEgor-Bee/flappy_bird.git)
cd flappy_bird

```

### 2. Создание и активация виртуального окружения

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate

```

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate

```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt

```

### 4. Запуск программы

```bash
python main.py

```

### 5. Управление в игре

* `Space` (Пробел) — прыжок птицы
* `R` — перезапуск игры после столкновения
