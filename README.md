## Описание проекта
Программа представляет собой классическую 2D-аркаду Flappy Bird. 
Цель игры — управлять птицей, пролетая между трубами и избегая столкновений. 
Реализована генерация препятствий, гравитация и подсчет очков.

## Функциональные возможности
### Основной функционал
- 🐦 Управление прыжком птицы с помощью пробела.
- 🚧 Процедурная генерация препятствий (труб).
- 💥 Определение столкновений (коллизий) с трубами и землей.
- 🔄 Перезапуск игры после поражения.


## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** macOS / Windows / Linux
- **Библиотеки:** 
  - `pygame` (версия указана в requirements.txt)
